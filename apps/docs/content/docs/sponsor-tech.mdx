## Zetaris: the evidence store every claim is checked against

Remove Zetaris and nothing can be marked verified.

- **Evidence store.** When a file is read, the worker publishes its passages as JSON to a Zetaris
  `FILESTORE` table, hands Zetaris the file's PDF rendition, and keeps Zetaris's own PDFBox reading
  of it: a second extraction, independent of Konkyo's. A file is marked Ready only after Zetaris
  answers for it. (`packages/zetaris/src/evidence.ts`)
- **Pre-check** that retrieved documents are present. (`checks.ts`)
- **Quote verification**: every quote of an answer in one Spark SQL statement, a `VALUES` list
  joined to Zetaris's text. The same check covers the Analyst's matrix, study items, lecture notes
  and audio briefs.
- **Topic watches**: each is a Lightning `REST` table over OpenAlex; new papers are found with one
  `LEFT ANTI JOIN` against the DOIs already seen. (`watch.ts`)

## Meterless: memory, world state and long tasks

The engines are vendored unchanged (Apache-2.0) in `packages/meterless` and driven from
`packages/agents`.

- **H-MEM** (`memory.ts`): a 👎 with a reason, "wrong passage", or "this item is wrong" becomes a
  correction in your memory, with where it came from. The Planner reads relevant corrections
  before every answer; 👍/👎 adjust the confidence of the memories an answer used. Settings →
  Memory shows, edits and forgets them.
- **World Model** (`analyst.ts`): each comparison is recorded as sources, claims and
  `supports` / `contradicts` / `qualifies` relations, each with the passage it was read from.
- **Markovian** (`scout.ts`): deep search screens what it found in bounded steps that carry only
  the shortlist forward; its estimate of tokens saved is shown and logged.

## OpenAI: the models that plan, write, check and teach

Every agent runs on an OpenAI model chosen for its role by a measured cost and quality benchmark
(the table is in [The agents and their trace](/agents-and-traces)). Embeddings for search are
`text-embedding-3-small`. Each role has a fallback model, and the switch is logged.

## ElevenLabs: listening and speaking

- **Recordings and lectures** are transcribed with Scribe (`scribe_v2`), word timings kept, so a
  citation can play the moment it quotes. (`packages/ingest/src/transcript.ts`)
- **Audio briefs**: two voices talk a folder through in one Text-to-Dialogue request
  (`eleven_v3`); every quote they read was checked first. (`packages/ingest/src/dialogue.ts`)
- **Study sounds** (right, try again, hint, round done, day seven) were made once with its sound
  effects model and ship as small files.

## Composio: Gmail, Google Drive and Notion

Connectors run through Composio: each person links their own account, and every tool call is
pinned to a measured toolkit version. Attachments, documents and pages import through the same
pipeline as an upload. (`packages/connectors/src/index.ts`)

## OpenAlex: open papers

- **Deep search** looks up open-access papers on OpenAlex when your library runs out.
  (`packages/agents/src/scout.ts`)
- **Citation records**: a DOI or title is matched on OpenAlex for authors, venue and licence.
  (`packages/ingest/src/metadata.ts`)
- **Topic watches** are Zetaris `REST` tables over the OpenAlex API (see Zetaris above).
