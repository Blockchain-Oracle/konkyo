title: The same check, everywhere
description: Practice answer keys, draft checks, audio briefs, articles and watch findings are all checked against your sources before you see them.

The check that ticks a citation isn't only for answers. Wherever Konkyo shows you something taken
from your sources, its quote was found first: in Zetaris almost everywhere, and in code for a
watch's stances.

| Where | What is checked | What fails |
|---|---|---|
| **Answers** | Each quote in code, then in one Zetaris statement; the Verifier judges support | The sentence is rewritten, at most twice, then dropped |
| **Compare table** | Each stance's quote in Zetaris | The stance isn't shown |
| **Practice** | The Tutor drafts; code checks the question's shape; the Verifier checks the answer key; Zetaris confirms the quote | The question is never kept |
| **Find the evidence** | Its three wrong passages are your nearest passages that *don't* state the claim (the Verifier removes any that do) | |
| **Typed answers** | Code grades first (exact words, a close spelling); the Grader settles the rest as right, close or wrong, never giving the answer away | |
| **This is wrong** | The Verifier re-checks with your reason | If it agrees, the question is marked wrong and remembered |
| **Check my draft** | Each claim against your sources; every quote it shows, in one Zetaris statement | A quote not confirmed makes the claim *Not found* |
| **Find a source** | Only passages whose quotes Zetaris confirms are offered | |
| **Lecture notes** | Each point's quote in code and in Zetaris | The point is dropped |
| **Audio briefs** | Each line's quote in code and in Zetaris, then each line by the Verifier | The line isn't recorded; fewer than four lines and no brief is made |
| **Articles** | Your own passages' quotes are checked in Zetaris again as it publishes | The article shows the quote as not re-found |
| **Watch findings** | The stance's quote must be in your passage, checked in code | The paper is shown as new to your library |

## Real numbers from testing

| Run | Result |
|---|---|
| An answer with Compare on | 3 answer quotes and 7 table quotes found, 0 rewritten, 19 s |
| Practice from a sample course | The first round ready once 6 questions had passed |
| Check my draft on three claims | 2 supported, 1 contradicted, 8.1 s |
| An audio brief of the essay space (8 passages from 2 of its papers) | Zetaris found 8 of 8 quotes; the Verifier passed 6 of 8 lines; 6 lines recorded, 1:11 |
| A watch on sleep spindles | 25 recent open-access papers through a Zetaris table; the newest 3 placed against the library |
