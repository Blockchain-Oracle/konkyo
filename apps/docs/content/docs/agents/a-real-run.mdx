Nishida and Walker report that, after a motor-skill task, greater spindle activity in the learning
hemisphere relative to the non-learning hemisphere was associated with greater offline memory
improvement during a nap <sup>1 ✓</sup>. Muehlroth et al. report that precise coupling of fast
spindles to slow-oscillation peaks promotes declarative-memory consolidation across younger and
older adults <sup>2 ✓</sup>. Diekelmann describes spindles as associated with memory consolidation,
but says it remains unclear whether their relationship with memory is causal or whether externally
triggered spindles enhance memory <sup>3 ✓</sup>. Thus, the papers support an association between
spindles and memory consolidation, but the passages do not establish that spindles themselves cause
the improvement <sup>1 ✓</sup> <sup>2 ✓</sup> <sup>3 ✓</sup>.
