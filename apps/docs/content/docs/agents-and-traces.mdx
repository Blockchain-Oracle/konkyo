title: The agents and their trace
description: Who does what, with which model, and how to read the trace.
---

| Agent | Does | Model |
|---|---|---|
| Planner | Stand-alone question, 1–3 searches, comparison flag; reads H-MEM corrections first; replans more broadly when the first search is thin; if no Planner model answers, searches the question as asked | Nemotron 3 Ultra |
| Retriever | Hybrid search: pgvector and Postgres full text, fused by Reciprocal Rank Fusion | Nemotron 3.5 Embed (question as a query, passages as passages) |
| Writer | Cited draft, one finding per sentence; rewrites rejected sentences | OpenAI `gpt-6-luna` |
| Verifier | Code check, one Zetaris statement, support judgement; at most two rewrite rounds | OpenAI `gpt-6-luna` (low reasoning) |
| Analyst | Claims × sources with stances, quotes checked in Zetaris, World Model; places each paper a watch finds against your sources (agrees, disagrees or new, your passage quoted) | OpenAI `gpt-6-luna` (low) |
| Scout | Deep search over OpenAlex and the web (OpenAI's web search; Wikipedia if it fails), screened in Markovian steps | Nemotron 3.5 Lightning plans; Nemotron 3 Ultra screens |
| Tutor | Practice items; every answer key checked by the Verifier, every quote in Zetaris | OpenAI `gpt-6-luna` |

Every role's fallback is on the other provider (OpenAI's roles fall back to Nemotron 3 Ultra,
Nemotron's to `gpt-6-luna`), with a reserve on a third model; they're tried in turn, the ones
answering first, so an outage, an empty account or NVIDIA's free tier filling up doesn't stop an
answer while any of them can answer. A call falls back on an error, a malformed reply, or a stall (no answer within
45 seconds, or no first word of a stream within 25; 12 for the Planner, 90 for the Tutor's
drafts); the switch is logged as `escalated_to_fallback`. On NVIDIA's free tier a call that runs
past its usual time is also asked again (a hedged request: the first answer wins), and a model
that answers 429 is tried second for the next minute; an account out of credit, for ten.

The models were picked by measured benchmarks: OpenAI's on testing (`gpt-6-luna` wrote 9/9 quotes
verbatim and, at low reasoning, made 0/10 false rejections and caught 6/6 planted errors) and
Nemotron's on NVIDIA's API on testing (Ultra with thinking off passed every test; Lightning judged
as well only when thinking and never kept the cited format).

## Reading a trace

Every run writes `logs/<runId>.jsonl`, one JSON line per step:

```json
{"ts":"2026-10-17T12:31:04.118Z","runId":"…","agent":"verifier","step":"verify_0","action":"queried_zetaris","sqlHash":"0cc394679bad","rowsReturned":2,"verdict":"2/2 quotes found","latencyMs":3317}
```

| Field | Meaning |
|---|---|
| `agent`, `step`, `action` | Who did what: `planned`, `hybrid_search`, `broadened_search`, `hybrid_search_broadened`, `not_in_library`, `offered_scout`, `finding_agrees`, `finding_disagrees`, `finding_new`, `queried_zetaris`, `drafted_answer`, `rejected_to_writer`, `revised_sentences`, `approved`, `asserted_world_model`, `read_hmem` |
| `model`, `tokens`, `latencyMs` | Which model, at what cost and speed |
| `sqlHash`, `rowsReturned` | Which Zetaris statement (by hash) and what came back |
| `verdict`, `detail` | The decision, and its reasons |

The app shows the same run as the answer's receipt.
